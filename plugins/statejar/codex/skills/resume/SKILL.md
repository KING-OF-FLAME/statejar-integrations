---
name: resume
description: Resume StateJar memory for Codex after it was paused. Use only when the user asks to resume StateJar memory.
---

Run this from the plugin's root folder (three folders above this file):

    python3 scripts/statejar_hook.py resume --client codex

Tell the user StateJar memory is on again: recall at the next session start or prompt, capture from the next prompt.
